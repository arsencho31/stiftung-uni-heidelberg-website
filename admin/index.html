Anmelden

Dieses Panel veröffentlicht Artikel direkt im GitHub-Repository der Website. Zum Anmelden brauchen Sie einen persönlichen Zugriffstoken (einmalig erstellen, bleibt nur in Ihrem Browser).

So erstellen Sie den Token (2 Minuten)
  1. Öffnen Sie github.com/settings/personal-access-tokens/new (bei GitHub angemeldet).
  2. „Repository access“: Only select repositories → stiftung-uni-heidelberg-website wählen.
  3. „Permissions“ → „Repository permissions“ → Contents: Read and write.
  4. „Generate token“ klicken und den Token (beginnt mit github_pat_) hier einfügen.

Weitere Redakteur:innen: unter GitHub → Repository → Settings → Collaborators einladen; jede Person erstellt ihren eigenen Token.
